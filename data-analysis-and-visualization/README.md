**Learning objective:** By the end of this lesson, students will be able to create usable visualizations for data analysis.

Once we've gathered data through APIs or web scraping, we often want to analyze it and visualize the results.  Python libraries like `pandas` and `matplotlib` make this a breeze.

## Exercise

**Combining data sources:** Combine data from multiple sources (for example, an API and a CSV file) using `pandas` and perform analysis on the combined dataset.
